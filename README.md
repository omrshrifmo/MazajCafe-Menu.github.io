# منيو كافيه مزاج — Mazaj Cafe Online Menu

موقع منيو إلكتروني سريع وخفيف لكافيه مزاج (Mazaj Cafe)، مُحسّن للعمل على كافة أجهزة الهواتف المحمولة والمتصفحات بأعلى جودة عرض وأقصى سرعة تحميل ممكنة.

🔗 **الرابط المباشر:** [https://omrshrifmo.github.io/MazajCafe-Menu.github.io/](https://omrshrifmo.github.io/MazajCafe-Menu.github.io/)

## ⚡ معايير الأداء والسرعة (Performance Optimization)

- **تقليل استهلاك البيانات المبدئي بنسبة 92%:**  
  تم تخفيض حجم التحميل المبدئي من ~9.6 ميجابايت إلى **~750 كيلوبايت فقط** لفتح المعرض في أجزاء من الثانية.
- **جودة بصرية كاملة (48.6 dB PSNR):**  
  الاحتفاظ بالدقة الماستر الكاملة (6250 × 4419 بكسل) مع إعادة تشفير WebP عالية الكفاءة بدون أي فقدان في دقة النصوص أو الأسعار.
- **التحميل التدريجي (Progressive Loading):**  
  عرض صور معاينة فائقة النقاء (1800px) فوراً للمستخدم، وترقية الجودة في الخلفية تلقائياً للنسخة الماستر الكاملة.
- **التحميل الكسول (Lazy Loading):**  
  تفعيل `loading="lazy"` للبطاقات لتقليل الضغط على الشبكة والذاكرة.
- **ملفات CSS و JS مضغوطة ومفصولة (Minification):**  
  تم ضغط الأنماط والسكريبتات بالكامل باستخدام `esbuild` (`style.min.css` 10.5 KB و `app.min.js` 8.0 KB).
- **سياسة التخزين المؤقت (Caching Headers & Service Worker):**  
  ملف `_headers` وسياسة كاش طويلة المدى لجميع الأصول الثابتة، مع دعم `sw.js` للعمل بدون إنترنت (Offline PWA).
- **سلاسة الحركة والتحكم (60/120 FPS):**  
  إدارة التكبير والتحريك عبر `requestAnimationFrame` لمنع أي تقطيع أو تهنيج على شاشات الهواتف.
- **إيماءات الموبايل:**  
  دعم السحب بالأصبع (Swipe) للتنقل بين الصفحات، والنقر المزدوج (Double-tap) للتكبير، والقرص (Pinch-to-zoom).
